## 3. Time series

| Friday | 26.2 |
| Monday | 35.6 |
| Saturday | 23.2 |
| Sunday | 18.0 |
| Thursday | 27.9 |

Weekly seasonality is strong (Mondays ≈ 36/day vs Sundays ≈ 18/day), so the incident detector adjusts for weekday. Incidents are spikes in a single category, so they are detected per category (see `atlas.ml.anomaly`), not on total volume.

## 4. Operations: SLA and satisfaction

| sla_breached | avg CSAT |
|---|---|
| False | 4.23 |
| True | 3.14 |

Spearman(resolution_hours, csat) = **-0.08**: raw hours barely matter, but **breaching the SLA** drops CSAT by more than a point. Getting the *priority* right (and therefore the SLA clock) is what protects satisfaction.

## 5. Unstructured text

Ticket length: median **68** chars, p95 **110** chars.

**14.8%** of tickets contain personal data (CPF / e-mail / phone) → masked before training, retrieval, logging and any LLM call (LGPD).

| category | most discriminative terms |
|---|---|
| account | minha conta, conta, minha, senha, mail, mail cadastrado, na minha, alterar mail |
| billing | valor, foi, cobranca, vezes, fatura, do, paguei, nao foi |
| returns | produto, trocar, quero cancelar, cancelar, devolucao, devolver, quero, errado |
| shipping | entrega, de entrega, meu pedido, prazo, esta, endereco de, entrega do, alterar endereco |
| technical | erro, erro ao, app, as, ao, no navegador, nao responde, botao de |

Terms are highly category-specific, which is why a linear TF-IDF model is a strong, cheap and explainable baseline before reaching for an LLM classifier.
